# 🚀 國中知識星航

國中七～九年級全科學習**遊戲**。純靜態網頁（HTML + CSS + JavaScript），不需要建置、不需要後端、不需要任何 API 金鑰，直接部署到 GitHub Pages。

## 遊戲怎麼玩

知識星系被「遺忘迷霧」籠罩了。玩家駕駛太空船，從**星際航圖**飛到各科星系，再降落到一顆顆星球（每顆星球＝一個課綱主題）。每顆星球有三個能量核心，全部拿到星球就會完全點亮（出現光環、月亮和旗子）：

| 核心 | 做什麼 |
|---|---|
| 📡 探索 | **任務對話**（導覽角色帶出故事）→ **互動實驗室**（動手拉滑桿、點圖形、按開關，完成操作任務來發現觀念）→ **知識碎片**（掃描訊號源收集資料，或把被迷霧偷走的關鍵字放回去） |
| 🎮 試煉 | 依單元內容出現不同小遊戲：**記憶翻牌、泡泡射擊、隕石攔截（限時分類）、連星座（排順序）、拼句子、連連看** |
| 👾 Boss 戰 | 回合制對戰：答對發射雷射、連擊有爆擊；答錯被反擊扣愛心。有「掃描」「護盾」兩種道具，題型混合選擇題與是非判斷 |

其他模式：

- **🎯 章節複習**：選年級 → 選科目 → 選章節，針對比較弱的章節做「弱點特訓」（見下方說明）。
- **⚔️ 雙人對戰**：兩人同一台裝置分割畫面，先答對的人把能量球推向對手（鍵盤左邊 1234 選、5 確定；右邊 7890 選、－ 確定；Enter 下一題，也可以觸控）。可以只出指定章節；題目出完時，球比較靠近對方的人獲勝。
- **👑 星系守護者**：單科跨星球的大 Boss。
- **⏱ 迷霧突襲**：60 秒內擊退越多迷霧怪越好，也可以只出指定章節。
- **📒 錯題復仇戰**：答錯的題目（包括知識碎片的快問）會留下來，再答對 2 次才消失。
- **📔 圖鑑**：探索過的星球會留下重點筆記，考前可以翻。
- **🛠 機庫**：用星塵換不同的太空船。另有等級、連續天數、每日任務、多位使用者與備份。

學習紀錄只存在瀏覽器（localStorage），不會上傳到任何地方。

### 作答規則：選好 → 確定作答 → 看說明 → 下一題

所有要作答的地方都用同一套手順，不能亂點到對為止，也不會自動跳題：

1. **選擇**：點選答案（還可以改選、拿回來重排）。
2. **確定作答**：按「確定作答」（遊戲裡是「發射」「翻開它」）才判定。沒選好按不下去。
3. **說明**：每一題只有一次機會，判定後就鎖住。答對、答錯都會說明原因；答錯會公布正確答案。
4. **下一題**：讀完說明按「下一題／繼續」才前進。答錯時按鈕會先鎖 1.5 秒；沒有跳過的按鈕。

各關卡的作答方式：

| 關卡 | 怎麼作答 |
|---|---|
| Boss 戰、星系守護者、迷霧突襲、錯題復仇戰、快問 | 選擇題、是非題都先選再確定；公布後每個選項底下都寫出為什麼對或錯，並標示「你的答案」。**同一場戰鬥每題只出現一次**，Boss 戰會把探索時答過的相同題目排到最後；突襲看說明時計時暫停 |
| 互動實驗室 | 可以自由動手操作、看讀數，做好之後按「確定作答」才判定，每個任務一次機會；答錯會說明你的答案哪裡不對，並把畫面換成正確答案 |
| 修復關鍵字 | 把字卡放進全部空格（點空格可以拿回來），按一次「確定作答」，逐格說明填錯的字卡其實屬於哪裡 |
| 掃描辨識 | 選一個訊號源再確定；答錯會說明你選的那個其實是什麼 |
| 記憶翻牌 | 先記住說明牌位置再蓋牌，依照題目選一張再按「翻開它」 |
| 泡泡射擊、隕石攔截 | 瞄準後按「發射」；隕石落到底會停住等你作答，不會自動跳過 |
| 連星座、拼句子、連連看 | 全部排好（可以退回重排）再按「確定作答」，逐一說明放錯的位置 |
| 雙人對戰 | 各自先選再按自己那邊的「確定」；每題每人一次機會，答錯失去作答權並看到原因，每題結束兩邊都公布說明 |
| 弱點特訓 | 和 Boss 戰一樣先選再確定、每題只出一次；不會輸，題目全部做完才結算，答錯的題目會記進錯題本 |

錯題本會列出正確答案的說明，也可以展開看「其他選項為什麼錯」。

### 章節複習：針對比較弱的章節

主選單的「🎯 複習」（或星系頁、星球頁的按鈕）：

1. **選年級、選科目、選章節**：章節依學期排列，可以跨科目一起選，選好的章節會記住。
2. **看出哪一章比較弱**：每一章都會顯示最近的答對率和錯題數，分成 🔴 待加強、🟡 還不穩、🟢 很穩、⚪ 還沒練習。按「🎯 自動選出弱點」會把這一科的 🔴、🟡 章節全部選起來。
3. **弱點特訓**：可以選 10 題、20 題或全部。
   - 先複習重點：每章一張知識碎片，讀完再把關鍵字填回去（可以關掉）。
   - 再做特訓：各章輪流出題，錯題本裡的題目優先。畫面上每一章是一顆被迷霧籠罩的星球，答對越多迷霧散得越開。
   - 最後看結算：每一章這次答對幾題、掌握度的變化（例如 🔴 → 🟡），以及這次答錯的題目和說明。可以「再特訓一次」，或「只練這次答錯的題目」。

**掌握度怎麼算**：每一章記錄最近 20 次作答的對錯，所有關卡都算，包括實驗任務、知識碎片、小遊戲和各種戰鬥。另外也看錯題本裡這一章還剩幾題。

| 掌握度 | 條件 |
|---|---|
| 🔴 待加強 | 最近答對率低於 60%，或錯題本裡還有 3 題以上 |
| 🟡 還不穩 | 最近答對率低於 80%，或錯題本裡還有題目 |
| 🟢 很穩 | 最近答對率 80% 以上，而且沒有錯題 |
| ⚪ 還沒練習 | 作答少於 3 次 |

星系頁的星球旁、「我的進度」也會標出待加強的章節。迷霧突襲、雙人對戰的「📑 出題章節」可以只出指定章節，不選就是全部章節。

## 介面

- 第一次進入會「登艦」：輸入名字、選年級，並用三張圖說明玩法。
- 首頁最上方是「下一站」按鈕，一鍵接著上次的進度。
- 手機上主選單（星圖、複習、圖鑑、對戰、錯題、我的）在螢幕底部，錯題本有數字提醒；進入關卡後會隱藏選單與頁尾，畫面專心在遊戲上。
- 關卡進行到一半按 ✕ 會先確認，避免誤觸。


### 題庫（`data/<科目>.json`）

```json
{"id":"ma7a1","g":7,"s":"上","t":"整數與數線","k":"範圍說明","q":[
  ["題目","正確答案","錯誤選項1","錯誤選項2","錯誤選項3",
   "正確答案的說明","錯誤選項1為什麼錯","錯誤選項2為什麼錯","錯誤選項3為什麼錯"]
]}
```

每題 9 個欄位，**每個錯誤選項都要寫原因**（說清楚這個選項其實是什麼，或是犯了哪種錯會選到它），作答後會顯示在選項底下。

### 課程（`data/lessons/<科目>.json`）

```json
"ma7a1": {
  "ic": "➖",
  "hook": "任務故事……",
  "cards": [
    {"e": "📏", "t": "卡片標題", "b": "內文，**粗體**是會被迷霧偷走的關鍵字",
     "flip": [["訊號源名稱","掃描後看到的資料"]],
     "chk": ["題目","正確答案","錯誤1","錯誤2","正確答案的說明","錯誤1為什麼錯","錯誤2為什麼錯"]}
  ],
  "game": {"type":"match", "title":"…", "pairs":[["左","右"]], "recap":"一句話複習"}
}
```

- 卡片有 `flip` → 變成「掃描」任務；沒有 → 變成「修復關鍵字」任務。`chk` 會加入 Boss 戰的題目。
- `game.type`：`match`（翻牌／泡泡／連連看）、`sort`（隕石攔截，`buckets` + `items: [文字, 分類編號]`）、`order`（連星座／拼句子，`items` 依正確順序）。

### 實驗室（`js/labs.js`、`js/labs2.js`）

每個實驗是一個物件：`init()` 初始狀態、`ctrl` 控制項（滑桿／按鈕／開關／選項，也可以是依任務變化的函式 `ctrl(s)`）、`view(s)` 回傳畫面（SVG 或 HTML 字串）、`read(s)` 讀數、`tap(s, id)` 點擊圖形、`missions` 任務（`set` 進入設定、`ok` 判定、`say` 說明、`sol` 正確答案（答錯時用來公布，也用於測試）、`hint` 提示、`why` 答錯原因，可省略）。按下「確定作答」後 `s.judged` 會變成 `true`，畫面可以據此公布結果；作答前畫面和讀數不要直接透露「對了沒」。

`labs2.js` 另有幾個可重複使用的引擎，新增單元時直接填資料即可：`timeLab`（時光機）、`huntLab`（線索偵探，文字用 `{字句|說明|*}` 標記）、`pinLab`（地圖釘）、`comicLab`（四格漫畫排序），以及 `labs.js` 的 `machine`（組裝機）。

修改後請執行：

```bash
node scripts/validate.mjs
```

```bash
node scripts/test-labs.mjs
```
