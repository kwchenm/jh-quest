# 🚀 國中知識星航

國中七～九年級全科學習**遊戲**。純靜態網頁（HTML + CSS + JavaScript），不需要建置、不需要後端、不需要任何 API 金鑰，直接部署到 GitHub Pages。

## 遊戲怎麼玩

知識星系被「遺忘迷霧」籠罩了。玩家駕駛太空船，從**星際航圖**飛到各科星系，再降落到一顆顆星球（每顆星球＝一個課綱主題）。每顆星球有三個能量核心，全部拿到星球就會完全點亮（出現光環、月亮和旗子）：

| 核心 | 做什麼 |
|---|---|
| 📡 探索 | **任務對話**（導覽角色帶出故事）→ **互動實驗室**（動手拉滑桿、點圖形、按開關，完成操作任務來發現觀念）→ **知識碎片**（掃描訊號源收集資料，或把被迷霧偷走的關鍵字放回去） |
| 🎮 試煉 | 依單元內容出現不同小遊戲：**記憶翻牌、泡泡射擊、隕石攔截（限時分類）、連星座（排順序）、拼句子、連連看** |
| 👾 Boss 戰 | 回合制對戰：答對發射雷射、連擊有爆擊；答錯被反擊扣愛心。有「掃描」「護盾」兩種道具，題型混合選擇題與是非判斷 |

其他模式：

- **⚔️ 雙人對戰**：兩人同一台裝置分割畫面，先答對的人把能量球推向對手（鍵盤左 1234、右 7890，也可以觸控）。
- **👑 星系守護者**：單科跨星球的大 Boss。
- **⏱ 迷霧突襲**：60 秒內擊退越多迷霧怪越好。
- **📒 錯題復仇戰**：答錯的題目會留下來，再答對 2 次才消失。
- **📔 圖鑑**：探索過的星球會留下重點筆記，考前可以翻。
- **🛠 機庫**：用星塵換不同的太空船。另有等級、連續天數、每日任務、多位使用者與備份。

學習紀錄只存在瀏覽器（localStorage），不會上傳到任何地方。

## 互動實驗室（53 個）

「先動手、再命名」：每個實驗有 2～4 個操作任務，完成後才說明觀念。例如：

- **數學**：數線跳跳蛙、天平解方程式、坐標定位、乘法公式面積拼圖、畢氏定理、直線與拋物線（調參數穿過星星）、多邊形內角、圓周角、擲骰子大數據…
- **理化**：浮沉水槽（密度）、聲波製造機（可以聽聲音）、酸鹼調色燒杯、反應加速器、F = ma 測試場、串並聯電路板、電磁鐵…
- **生物／地科**：細胞顯微鏡、光合作用工廠、遺傳方格機、生態平衡、板塊推推樂、月相軌道儀、探空氣球、地球體溫計
- **地理／歷史／公民**：臺灣地圖（史前遺址、清代港口、地名、四大區域、季風）、時區轉盤、人口金字塔、橫越中國列車、園遊會定價機（供需）、人生年齡滑桿（行為能力與責任年齡）
- **英語**：be 動詞機器、時光動詞機、比大小擂台、主動被動翻轉機… 共 10 台「句子機器」
- **國文**：錯字獵人、造字熔爐（六書）、詩句解剖臺（格律）

沒有實驗室的單元（35 個）仍有任務對話、知識碎片、小遊戲與 Boss 戰。

## 內容範圍

| 科目 | 年級 |
|---|---|
| 國文、英語、數學、歷史、地理、公民 | 七～九年級，每學期 2 個主題 |
| 生物 | 七年級 |
| 理化 | 八～九年級 |

共 **88 顆星球、496 題**。內容依教育部 **108 課綱**的學習內容編寫，只收康軒、翰林、南一三個版本**共通**的主題。各版本章節順序略有不同，請用「年級＋主題名稱」對照課本。

> 內容為原創編寫，沒有逐題對照課本或第二人審稿；法規、數據類的內容（例如公民科的法定年齡）以編寫當下為準，實驗室中的部分數值為示意。發現錯誤請直接修改對應的檔案。

## 本機執行

```bash
python -m http.server 5173
```

然後開啟 <http://localhost:5173>。（直接雙擊 index.html 無法載入資料，需要透過本機伺服器。）

## 檔案結構

```
index.html
css/style.css
js/app.js            遊戲主程式（星圖、任務流程、小遊戲、戰鬥、對戰、圖鑑）
js/labs.js           互動實驗室（以單元代號為 key）
data/manifest.json   科目清單（名稱、圖示、導覽角色）
data/<科目>.json     題庫
data/lessons/<科目>.json  每個單元的任務故事、知識卡、小遊戲資料
scripts/validate.mjs   資料格式檢查
scripts/test-labs.mjs  實驗室測試（每個任務都能完成）
scripts/autoplay.js    瀏覽器端自動試玩（開發用）
```

### 題庫（`data/<科目>.json`）

```json
{"id":"ma7a1","g":7,"s":"上","t":"整數與數線","k":"範圍說明","q":[
  ["題目","正確答案","錯誤選項1","錯誤選項2","錯誤選項3","解析"]
]}
```

### 課程（`data/lessons/<科目>.json`）

```json
"ma7a1": {
  "ic": "➖",
  "hook": "任務故事……",
  "cards": [
    {"e": "📏", "t": "卡片標題", "b": "內文，**粗體**是會被迷霧偷走的關鍵字",
     "flip": [["訊號源名稱","掃描後看到的資料"]],
     "chk": ["題目","正確答案","錯誤1","錯誤2"]}
  ],
  "game": {"type":"match", "title":"…", "pairs":[["左","右"]], "recap":"一句話複習"}
}
```

- 卡片有 `flip` → 變成「掃描」任務；沒有 → 變成「修復關鍵字」任務。`chk` 會加入 Boss 戰的題目。
- `game.type`：`match`（翻牌／泡泡／連連看）、`sort`（隕石攔截，`buckets` + `items: [文字, 分類編號]`）、`order`（連星座／拼句子，`items` 依正確順序）。

### 實驗室（`js/labs.js`）

每個實驗是一個物件：`init()` 初始狀態、`ctrl` 控制項（滑桿／按鈕／開關／選項）、`view(s)` 回傳畫面（SVG 或 HTML 字串）、`read(s)` 讀數、`tap(s, id)` 點擊圖形、`missions` 任務（`set` 進入設定、`ok` 判定、`say` 完成說明、`sol` 測試用解法）。

修改後請執行：

```bash
node scripts/validate.mjs
```

```bash
node scripts/test-labs.mjs
```
