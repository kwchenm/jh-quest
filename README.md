# 🚀 國中知識星航

國中七～九年級全科「**先學再玩**」學習網站。純靜態網頁（HTML + CSS + JavaScript），不需要建置、不需要後端、**不需要任何 API 金鑰**，直接部署到 GitHub Pages。

## 學習方式：每一站四個階段

| 階段 | 內容 |
|---|---|
| 🎯 任務簡報 | 導覽角色用一段小故事帶出主題（例如「你是考古隊員，要把王朝排成時間線」），先勾起好奇心 |
| 📘 互動知識卡 | 3～4 張知識卡講重點，部分卡片要點開小卡翻面；**每張卡後面有「快問快答」，答對才能翻下一張** |
| 🎮 小遊戲 | 連連看、分類大挑戰、排排站（依先後順序排列），用玩的方式把重點再記一次 |
| ⚔️ 最終挑戰 | 8 題選擇題、3 顆愛心，依答對率拿 1～3 顆星；全部通過會得到本站徽章 |

另有**綜合挑戰**（單科跨單元 20 題）、**限時衝刺**（60 秒跨科搶答）、**錯題本**（答錯的題目自動收錄，再答對 2 次才移除）、**經驗值與等級**、**連續學習天數**、**音效開關**、多位使用者與備份匯出／匯入。

學習紀錄只存在瀏覽器（localStorage），不會上傳到任何地方。

## 內容範圍

| 科目 | 年級 |
|---|---|
| 國文、英語、數學、歷史、地理、公民 | 七～九年級，每學期 2 個主題 |
| 生物 | 七年級 |
| 理化 | 八～九年級 |
| 地球科學 | 九年級 |

共 **88 站（單元）、496 題**，每一站都有互動課程。內容依教育部 **108 課綱**的學習內容編寫，只收康軒、翰林、南一三個版本**共通**的主題，所以不論學校用哪個版本都能練習。各版本章節順序略有不同，請用「年級＋主題名稱」對照課本。

> 內容為原創編寫，沒有逐題對照課本或第二人審稿；法規、數據類的內容（例如公民科的法定年齡）以編寫當下為準。發現錯誤請直接修改 `data/` 下對應的檔案。

## 本機執行

```bash
python -m http.server 5173
```

然後開啟 <http://localhost:5173>。（直接雙擊 index.html 無法載入資料，需要透過本機伺服器。）

## 資料格式

```
data/
├── manifest.json        科目清單（名稱、圖示、導覽角色）
├── <科目>.json          題庫：每個單元一組選擇題
└── lessons/<科目>.json  互動課程：每個單元一份任務故事、知識卡、小遊戲
```

### 題庫（`data/<科目>.json`）

```json
{"id":"ma7a1","g":7,"s":"上","t":"整數與數線","k":"範圍說明","q":[
  ["題目","正確答案","錯誤選項1","錯誤選項2","錯誤選項3","解析"]
]}
```

正確答案固定寫在第 2 欄，遊戲出題時會自動打亂選項順序。

### 互動課程（`data/lessons/<科目>.json`）

以單元代號為 key：

```json
"ma7a1": {
  "ic": "➖",
  "hook": "任務故事……",
  "cards": [
    {"e": "📏", "t": "卡片標題", "b": "內文，**粗體**是重點",
     "flip": [["點開前","點開後"]],
     "chk": ["快問快答題目","正確答案","錯誤1","錯誤2"]}
  ],
  "game": {"type":"match", "title":"…", "pairs":[["左","右"]], "recap":"一句話複習"}
}
```

小遊戲三種：

- `match`：`pairs` 為 3～6 組 `[左, 右]`
- `sort`：`buckets` 為 2～4 個分類，`items` 為 `[文字, 分類編號]`
- `order`：`items` 依正確順序排列，遊戲時會自動打亂

新增或修改內容後，執行格式檢查（推送時也會自動檢查）：

```bash
node scripts/validate.mjs
```

## 部署

推送到 `main` 後，`.github/workflows/pages.yml` 會先跑格式檢查，再自動部署到 GitHub Pages（repo 的 **Settings → Pages → Source** 需選擇 **GitHub Actions**）。
